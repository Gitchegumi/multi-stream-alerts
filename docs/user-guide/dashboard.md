# Dashboard

The dashboard is the control surface for a channel workspace.

- **Alerts** manages canvases, browser-source URLs, alert assignments, and tests.
- **Assets** manages images, videos, and audio used by canvases.
- **Settings** manages the workspace name and links to integration settings.
- **Guide** opens the user guide inside the dashboard.

Integrations live under Settings because provider credentials and webhook configuration are administrative settings rather than day-to-day streaming controls.
