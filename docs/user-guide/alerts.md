# Alerts

Alert types are normalized event kinds such as `kofi.tipped`, `twitch.followed`, and `youtube.superchat`.

In the Alerts workspace, select a canvas and use the right panel to choose which alert types belong to it. A single canvas can receive many alert types, and the same alert type can be assigned to multiple canvases.

Use the test action beside an alert type to send a sample event through the current alert pipeline.
